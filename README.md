# bluetooth-speaker-esp32

Двошарова плата Bluetooth-колонки на ESP32, з ЦАП PCM5102A і підсилювачем TPA3116D2.

Відкрийте `BluetoothSpeaker.kicad_pro` у KiCad 10 зі стандартними бібліотеками символів, посадкових місць і 3D-моделей. Локальні бібліотеки зберігаються в `lib/`. Таблиці `sym-lib-table` та `fp-lib-table` посилаються на них відносно папки проєкту. Правила плати містяться в `BluetoothSpeaker.kicad_dru`.

Для механічного компонування доступна модель корпусу U7 у `lib/ul_TPA3116D2DAD/DAD0032A.stp`. PCB посилається на стандартні моделі KiCad для U7 та клемників J1/J3/J4. Якщо цих моделей немає в установленому наборі, відповідні корпуси можуть не відображатися у 3D.
